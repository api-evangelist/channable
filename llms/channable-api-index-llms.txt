# Channable

> Channable is a feed management and marketplace integration platform for online retailers, brands, and agencies. It optimizes and distributes product data to 2,500+ channels, marketplaces, and comparison sites, automates PPC advertising, and runs an order-connection layer that syncs orders, shipments, stock, and returns between marketplaces and a seller's ERP/e-commerce platform. The Channable order connection API (v1) exposes this order layer over REST with company-level bearer-token auth.

## API
- [Channable Order Connection API v1 — Reference](https://docs.channable.com/api/v1/): Orders, returns, shipments, stock updates, order attachments, transporters, and order statistics.
- Base URL: https://api.channable.com/v1
- Auth: company API token as `Authorization: Bearer <token>` (or `?access_token=<token>`). Tokens are generated by company owners in Company settings > Channable API.
- Rate limit: per company, leaky bucket, 2 requests/second, burst of 100.
